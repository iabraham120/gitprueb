Etiquetas HTML--MI referencia
Etiqueta Para que sirve Ejemplo
<table> Se utiliza para hacer tablas <table> <tr> <td> Alumno1 <td> <tr> <table>
<h1> Se utiliza UNA sola vez para poner un texto grande (titulo) <h1> SISTEMA <h1>
<p> Se utiliza para poner un parrafo de texto (paragraph) <p> Persona 3 es el mejor juego de la saga <p>
<ul> Se utiliza para hacer una lista desordenada <ul><li>Elemento1<li><li>Elemento2<li><ul>
<section> Se usa para dividir la info en secciones, diviendose estas en articulos <section><h2>COMPONENTES DE NVIDIA<h2>etc... <section>
