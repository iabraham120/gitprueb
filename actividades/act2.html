Explicacion de Codigo de C

CODIGO


#include 
int main() {
    int edad;
    printf("¿Cuántos años tienes? ");
    scanf("%d", &edad);

    if (edad >= 18) {
        printf("Eres mayor de edad.\n");
    } else {
        printf("Eres menor de edad.\n");
    }

    return 0;
}

Explicación del Código



#include <stdio.h> : 
Es una directiva de preprocesador que incluye la biblioteca estándar 

int main() {: 
Es la función principal del programa, donde comienza la ejecución.

    int edad; : 
Declara una variable de tipo entero llamada edad, que se usará para almacenar la edad ingresada por el usuario.

    printf("Introduce tu edad: "); : 
Imprime el mensaje en la consola.

    scanf("%d", &edad); : 
Lee un valor entero ingresado por el usuario y lo almacena en la variable edad.&edad pasa la dirección de la variable para almacenar el valor.

    if (edad >= 18) { : 
Inicia una estructura de control if que verifica si la edad ingresada es mayor o igual a 18.

        printf("Eres mayor de edad.\n"); : 
Si la condición es verdadera, se ejecuta esta línea que imprime "Eres mayor de edad." en la consola.

    } else { : 
Si la condición del if no se cumple (edad es menor de 18), se ejecuta el bloque else.

        printf("Eres menor de edad.\n");
    }        
    return 0; : 
Indica que la función main ha terminado correctamente y devuelve el valor 0 al sistema operativo, lo que generalmente significa que el programa se ejecutó sin errores.
